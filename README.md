# Coding Camp - Math for Data Science Assignment

This repository contains learning assignments and implementations for the Math for Data Science module in the Coding Camp program.

## Segments

### 1. Random Data Generation
Learning how to generate random datasets that follow specific statistical distributions.

### 2. Naive Bayes Classification
Implementing the Naive Bayes classification algorithm using the dataset generated from Segment 1.

### 3. A/B Testing
Conducting hypothesis testing to evaluate statistical significance between proportions.

#### Hypotheses Tested:
- **Null Hypothesis ($H_0$):** There is no difference between the two proportions ($p_1 = p_2$).
- **Alternative Hypothesis ($H_1$):** There is a difference between the two proportions ($p_1 \neq p_2$).
